**VOD** is a self-hosted video-on-demand platform. Admins upload videos through a resumable uploader; a background pipeline built on **Celery** and **FFmpeg** transcodes each file into an **adaptive bitrate (ABR) HLS** stream with up to seven quality levels; viewers browse and watch through a **Next.js** frontend with a custom **video.js** player. The backend is a **FastAPI** service with **PostgreSQL**, **Redis** and **MinIO** (S3-compatible object storage), fronted by **Caddy** and run with **Docker Compose** on a single small VPS.

## How each page is written

Most pages follow the same shape so they are quick to scan:

1. **Summary**: what the part does, in a few lines.
2. **Diagram**: where a picture explains it faster.
3. **How it works**: numbered steps, with links to the source files.
4. **Failure modes**: what goes wrong and how the system reacts.
5. **Trade-offs**: why it was built this way and what that costs.
