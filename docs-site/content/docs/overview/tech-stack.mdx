## Key choices in one line each

- **HLS over progressive MP4**: lets the player switch quality mid-stream as bandwidth changes, and segments cache well.
- **Object storage served by the proxy**: video bytes go MinIO → Caddy → browser and never pass through Python.
- **tus for uploads**: large files survive network drops and resume from the last chunk.
- **One processing pipeline at a time**: predictable CPU and memory use on a small server.
- **Separate frontend hosting**: the frontend scales on Vercel's edge independently of the backend VPS.

Each of these is explained in depth in [Architecture](/docs/architecture) and [Decisions & Incidents](/docs/decisions).
